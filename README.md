## 📌 Technical Overview
This repository serves as a practical reference for idiomatic Kotlin development. It highlights the expressive features that make Kotlin efficient, robust, and safe for modern mobile and backend systems.

### 💼 Core Architectural Topics
- **Type Inference & Immutability**: Value semantics with `val` vs `var`, smart casting, and type checks.
- **Control Flow & Pattern Matching**: Advanced `when` expressions, ranges, and loop idioms.
- **Functions & Lambdas**: Higher-order functions, lambda expressions, default arguments, and named parameters.
- **Null Safety Guarantees**: Safe calls (`?.`), Elvis operator (`?:`), and non-null assertions (`!!`).

## 🚀 Setup & Execution
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/hello-kotlin.git
   cd hello-kotlin
   ```
2. Run using `kotlinc`:
   ```bash
   kotlinc src/Main.kt -include-runtime -d hello.jar && java -jar hello.jar
   ```
